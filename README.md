# Exploratory Data Analysis of Movie Dataset using Python Pandas 🎬📊

## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on a raw movie dataset using Python and the Pandas library. The primary objective is to clean, process, and analyze movie metrics—such as Tomatometer ratings, genres, directors, and runtimes—to transform unstructured data into actionable insights. Additionally, an interactive Command-Line Interface (CLI) was built to allow dynamic filtering and quick retrieval of analytical findings.
